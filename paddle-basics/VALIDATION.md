# Validation

Проверено 15 ноября 2026 на Windows с OpenJDK 25.0.1 и JavaFX 21.0.2.

- Maven compile: BUILD SUCCESS, компиляция 5 Java-файлов с release 21.
- Проверки модели Paddle: исходное положение, все четыре границы, нормализация
  диагонали, обнуление скорости, одинаковое перемещение за одинаковое время
  при разных шагах обновления.
- Запущено настоящее окно GameApp: Scene 720 x 1280, изменение размера запрещено.
- Снимок Canvas: проверены серый фон и светлая пластина, выполнен визуальный осмотр.
- Через события JavaFX проверены удержание D, отпускание D и движение стрелкой влево.

Для проверок использовались временные отдельные программы; они не являются частью
игры. Мячи, блоки, очки и физика столкновений пока не реализованы.

## Обновление управления: только WASD

- Из GameApp удалены привязки LEFT, RIGHT, UP и DOWN.
- axis() принимает только две клавиши: отрицательное и положительное направление.
- Все пять Java-классов повторно скомпилированы с --release 21.
- Описание управления в README.md обновлено.
